# @gradient365/omegaui-landing

Omega POS marketing site. `omegaui-landing.com` (domain TBD).

## Stack

- Next.js 15 (App Router) + React 19
- TypeScript
- Tailwind v4 (postcss) — design tokens via CSS variables
- DM Sans + Instrument Serif italic + JetBrains Mono (self-hosted woff2)

## Develop

```
pnpm install
pnpm dev   # http://localhost:3010
```

## Origin

Ported from `_omega-landing-unpack/` (Figma Make export of "Omega Landing - Standalone.html"). Exact-same visuals first, animations layered on next.
